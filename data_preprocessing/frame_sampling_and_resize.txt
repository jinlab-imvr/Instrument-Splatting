DATASET VIDEO-SEQUENCE FRAME MANIFEST
=====================================

In-house preprocessing
----------------------
Temporal downsampling factor: 2 (the first clip frame is retained).
Input resolution: 1920 x 1080 pixels (width x height).
Output resolution: 640 x 352 pixels (width x height).
Resize operation: cv2.resize(frame, (640, 352)), using OpenCV's default
linear interpolation without cropping or padding.

Frame-ID convention
-------------------
For the In-house dataset, retained_frame_ids are the original source-video
frame IDs, and each sequence contains the first 100 retained IDs in temporal
order. For EndoVis, frame_ids correspond to the processed frameNNN.png names
and include the complete sequence used in the experiments.
